# Daybook

A one-day-at-a-time task list. Plan the day, tick things off, drag tasks between days, carry leftovers forward, and watch the sun rise as you finish.

Single file, no build step: open `index.html` or serve the folder as a static site.

**Test build note:** in this public version tasks are saved in the browser's local storage on each device (nothing is sent anywhere). Clearing site data clears the tasks.
